# MEMORA — مدیریت هوشمند حافظه

اپلیکیشن اندرویدی فارسی برای بررسی و مدیریت فضای ذخیره‌سازی.

## مشخصات اولیه
- رابط فارسی و راست‌چین
- تم تیره مشکی/سرمه‌ای با بنفش و نئون
- حداقل Android 6؛ سازگار با Android 9 و Galaxy S8+
- ساخت APK آزمایشی با GitHub Actions

## ساخت APK
از بخش **Actions**، گردش‌کار **Build MEMORA APK** را با گزینه **Run workflow** اجرا کنید. فایل APK در بخش Artifacts همان اجرا قرار می‌گیرد.

## نکته درباره دسترسی حافظه
اسکن فایل‌ها با دسترسی‌های رسمی اندروید و انتخاب پوشه توسط کاربر پیاده‌سازی خواهد شد. حذف فایل‌ها فقط پس از تأیید کاربر انجام می‌شود. دسترسی به داده‌های خصوصی برنامه‌های دیگر یا فایل‌های محافظت‌شده سیستم بدون مجوز ممکن نیست.
